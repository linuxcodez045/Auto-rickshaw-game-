AUTO RICKSHAW DRIFT LEAGUE - MAPS INCLUDED

assets/drift_race_track_free.glb   -> MAPS > Drift Race Track
assets/race_track_map.glb          -> MAPS > Race Track Map
Both load automatically. No file picking needed.

START ON WINDOWS
1. Extract the entire ZIP folder.
2. Double-click launch_game.bat (wait ~3 seconds for the browser).
3. Open MAPS and choose a map.

IMPORTANT
- Keep the assets folder beside index.html.
- Do not double-click index.html (browsers block local 3D files). Use launch_game.bat.
- Manual start: python -m http.server 8000, then open http://localhost:8000
